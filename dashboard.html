🎓 LeetCode YouTube Bot

Automated Daily Problem-Solving Content Generation

What Is This?

An end-to-end automated pipeline that fetches the LeetCode Problem of the Day, generates a correct C++ solution using AI, produces a narrated teaching video with subtitles, and uploads it to YouTube every single day with zero manual intervention.

How It Works

📥 Fetch POTD
🤖 Generate C++ Solution
📝 Create Script
🎙️ Generate Audio
🎬 Build Video
📺 Upload YouTube

Each step saves its output to disk. If the pipeline crashes, re-running it resumes from where it left off. The cache automatically clears when the date changes so each new day starts fresh.

Why Automate?

Creating daily educational coding content is extremely time-consuming. Without automation, a creator would need to:

  • 📖 Read and understand the problem
  • 💭 Think through an optimal solution
  • ✏️ Write and test the code
  • 🎙️ Record audio narration
  • 🎨 Design visual slides
  • 🎬 Edit the video
  • 📤 Upload with proper metadata

This bot automates the entire workflow so your channel publishes consistent, high-quality content daily with no effort.

Project Features

✅ Fully Automated

Runs daily at 07:00 IST via GitHub Actions with zero manual intervention required.

🔄 Resume-Safe

Each step saves output to disk and records completion status. If any step fails, re-running the pipeline resumes from that point.

🎯 Production Quality

Generates 1080p MP4 videos with syntax-highlighted code slides, natural TTS narration, and auto-generated subtitles.

🚀 Fast & Free

Uses free-tier APIs (Groq, gTTS, YouTube Data API). Each daily run makes only 2 LLM calls.

📊 Transparent Logging

Daily timestamped logs and pipeline state saved for full visibility into every run.

Getting Started

  1. Clone the repository
  2. Create a Python 3.11+ virtual environment
  3. Run pip install -r requirements.txt
  4. Get a free Groq API key at console.groq.com
  5. Set up YouTube OAuth credentials
  6. Configure .env with your keys
  7. Run python pipeline.py
