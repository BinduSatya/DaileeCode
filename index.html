Key Features
✅
Fully Automated
Runs daily at 07:00 IST via GitHub Actions. No manual steps, no babysitting.
🔄
Resume-Safe
Each step persists its output and logs completion. Re-runs pick up from the last successful checkpoint.
🎯
Production Quality
1080p MP4 with syntax-highlighted code frames, natural TTS narration, and auto-generated subtitles.
🚀
Fast & Free-Tier
Groq, gTTS, and the YouTube Data API are all free. Only 2 LLM calls per run.
📊
Transparent Logging
Timestamped run logs and pipeline state saved for full visibility into every daily execution.
Setup
Get the pipeline running locally or on CI
Quick Start
1
Clone the repository from GitHub ↗
2
Create a Python 3.11+ virtual environment: python -m venv .venv
3
Install dependencies: pip install -r requirements.txt
4
Get a free Groq API key at console.groq.com ↗
5
Set up YouTube OAuth 2.0 credentials in Google Cloud Console ↗
6
Configure your .env with the keys shown below
7
Run locally: python pipeline.py
8
Push to GitHub and enable the Actions workflow for daily automation at 07:00 IST
Environment Variables
# .env — required keys GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxx YOUTUBE_CLIENT_SECRETS=client_secrets.json YOUTUBE_CREDENTIALS=youtube_credentials.json CHANNEL_ID=UCxxxxxxxxxxxxxx VIDEO_CATEGORY_ID=27 # 27 = Education VIDEO_PRIVACY=public
